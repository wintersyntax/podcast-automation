in public files, documentation, examples, issues, pull requests, logs, release
artifacts, or Git author/committer metadata. Never copy a private address into this
policy. Use the verified GitHub noreply identity
`301267195+wintersyntax@users.noreply.github.com` for public Git author and committer
metadata; use fictional addresses in examples.

Before any public publication or push, inspect the staged diff and all history reachable from the proposed published refs,

rewrite history, or weaken publication checks to bypass a finding.
